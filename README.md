# AngadiMitra

## Vision

AngadiMitra is a multilingual grocery shop assistant designed to help shop owners and staff quickly answer customer queries about products, prices, brands, package sizes, availability, and inventory.

The goal is to make serving customers faster and easier through natural language search and AI assistance.
